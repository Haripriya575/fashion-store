# Fashion Store Ecommerce Web Application

A full-stack ecommerce web application developed using Java technologies for online fashion shopping.

## Features

* User Registration & Login
* Session Management
* Product Listing & Product Details
* Shopping Cart Functionality
* Checkout Page
* Dynamic Product Images
* Responsive UI Design

## Technologies Used

* Java
* JSP & Servlets
* JDBC
* MySQL
* HTML & CSS
* Apache Tomcat
* MVC Architecture

## Tools Used

* Eclipse IDE
* MySQL Workbench
* Git & GitHub

## Project Structure

* Frontend: JSP, HTML, CSS
* Backend: Java Servlets
* Database: MySQL
* Server: Apache Tomcat

## How to Run

1. Clone the repository
2. Import project into Eclipse
3. Configure Apache Tomcat Server
4. Create MySQL database and tables
5. Update database credentials
6. Run the project on server
